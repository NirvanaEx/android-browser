# Нативная защита переходов Banana Plus

Модуль ChromeXt для Banana 20.15 / Chromium 146.0.7680.31, пакеты org.triple.banana и org.triple.bananx. Для телефона обновляется существующий org.triple.banana с прежней подписью и данными.

## Устройство защиты

NavigationGuard устанавливает Xposed-перехватчики до создания WindowAndroid и вкладок. Проверяется полная JNI-сигнатура shouldIgnoreNavigation(NavigationHandle, GURL, boolean, boolean): boolean у трёх реализаций делегата этой версии движка. Правила применяются к назначениям основной страницы, включая каждый серверный редирект; возвращаемое true отменяет переход через штатный NavigationThrottle. Ни fetch-проверки с повтором запросов, ни перезагрузки/возврата на уже открывшийся рекламный сайт не используются.

NavigationStartup добавляет AsyncNavigationIntercept в disable-features до инициализации native FeatureList. Все остальные флаги сохраняются. Это заставляет движок дождаться решения фильтра перед запросом; ранняя асинхронная версия могла успеть отправить запрос или заменить документ ошибкой. Флаг задаётся только внутри процесса Banana, без изменения файлов командной строки или глобальных настроек телефона. Состояние проверяется через закрытый аутентифицированный API существующего менеджера скриптов.

NavigationRules сопоставляет только HTTP/HTTPS-хост, включая поддомены по границе DNS-меток, регистр и завершающую точку. Текст пути, query и userinfo не принимаются за домен. Сохраняются разрешающие исключения документов. Глобальными не становятся правила с ограничением исходного сайта, third-party или типом ресурса. Источники, лицензия и SHA-256 зафиксированы в navigation-rules-provenance.json.

Защита кликов/userscript 2.1.3 остаётся вторым слоем: она обрабатывает поглощение первого Play/клика, подмену href, окна и iframe. Нативный слой блокирует известные рекламные назначения при серверных переходах. Списки не являются гарантией распознавания новых неизвестных рекламных доменов.

## Исходники и выпуск

chromext/ содержит воспроизводимый снимок ChromeXt 3.8.2 (upstream 0a6253bb975f3bd868df1521cba039c40b9003ad) с уже использовавшимися исправлениями Chromium 146, русским менеджером скриптов и новым слоем навигации. Сборка выполняется только в GitHub Actions, workflow banana-plus-module.yml. Локально выполняются проверки, упаковка готового CI-модуля и подпись существующим ключом; секреты не попадают в GitHub.

package-native-update.py заменяет только вложенный APK модуля в проверенном установленном браузере, сохраняет manifest, исходный движок, native-библиотеки, фильтры, загрузчик и вложенный origin.apk. Подпись сверяется с исходной. Версия модуля повышена отдельно. Версия внешнего готового Chromium закреплена: её несогласованное повышение приводит к ChildProcessMismatchException из-за проверки скомпилированной версии и путей LSPatch. Эту проверку безопасности не отключаем.

Нативные классы R8 закреплены за указанной версией Banana. Для другой версии необходимо повторно проверить DEX и сигнатуры; молчаливый подбор методов по типу запрещён. Диагностика хранит только счётчики и последний заблокированный hostname, без путей, параметров, cookies, паролей или истории.

## Проверка

Окончательная квитанция: [verification-native-2026-10-16.json](verification-native-2026-10-16.json). Все 19 серверных/стартовых проверок, 23 регрессии кликов, пять проверок Play, длительные таймеры и оба реальных сайта прошли. Данные и все шесть скриптов сохранены, установленный APK подтверждён по SHA-256, временные подключения удалены. Промежуточная 1.0.0 не прошла проверку гонки асинхронного перехода и не считается готовым выпуском.
