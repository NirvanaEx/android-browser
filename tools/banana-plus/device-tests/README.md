# Проверка установленного модуля на Android

Требуется Python 3.11+, websocket-client, ADB и разрешённая отладка браузера на подключённом устройстве. Установка/переподпись APK этими скриптами не выполняется. Тестируется установленный org.triple.banana; Chrome/Edge на ПК не запускаются.

По умолчанию adb -d выбирает единственный USB-телефон. При необходимости задать BANANA_DEVICE и BANANA_ADB. Отчёты попадают только в игнорируемую build/banana-device-audit/; путь можно изменить через BANANA_AUDIT_OUT. Перед проверками менеджер скриптов Banana должен быть открыт хотя бы один раз, чтобы браузер сохранил собственный приватный адрес. Его URL и авторизационный токен не печатаются.

1. До обновления: python tools/banana-plus/device-tests/capture_before.py
2. После обновления: python tools/banana-plus/device-tests/check_after.py
3. Серверные переходы: python tools/banana-plus/device-tests/native_redirect_audit.py

Стенд создаёт собственный локальный HTTP-сервер и вкладки. Проверяет 301/302/303/307/308, цепочки, HTTP/HTTPS, нестандартный порт, новые вкладки, разрешённые переходы, отключённое соединение отладки и три холодных запуска. Fetch-перехват на ПК не включается. Отдельный маркер подтверждает сохранение исходного документа. После проверки собственные вкладки и forward/reverse удаляются; чужие вкладки и cookies/пароли не читаются.

Контрольный известный рекламный hostname должен отменяться нативным фильтром. При регрессии тест может попытаться обратиться к указанному рекламному адресу; содержимое страницы не извлекается. Поэтому стенд запускается только в разрешённом для такой проверки браузере.
