# Upgrid icon

Created from scratch on 2026-09-30 with the built-in imagegen tool.
`upgrid-icon-master.png` is the original; `upgrid-icon-432.png` is the Android
resource, resampled with System.Drawing HighQualityBicubic. The overlay exports
it into Chromium's base APK resources. Both launcher entries use an adaptive
icon; `upgrid_monochrome.xml` provides a vector silhouette for themed icons.

Generation prompt:

> Use case: logo-brand. Create a brand new polished Android browser app icon for
> Upgrid. A single distinctive geometric U symbol that suggests upward motion
> and an open window. Minimal bold silhouette, precise continuous geometry,
> warm golden yellow mark consistent with the existing player's yellow accent,
> on a deep charcoal full bleed square background. Flat vector-like finish,
> sharp clean edges, carefully balanced negative space, strong legibility at
> 48 pixels. Center all essential mark geometry in the central 60% of the square
> to fit Android adaptive icon masks. One final icon, square canvas. No text,
> no letters other than the abstract U shape, no mockup, no device, no shadow
> outside icon, no watermark, no browser logos, no globe, no Chrome or Firefox
> references.
