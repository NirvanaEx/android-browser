# Перенос закладок

Начиная с 0.6.5 в меню закладок включён штатный импорт HTML-файла.
Путь: меню браузера → Закладки → меню закладок → Импорт закладок.
Файл выбирается системным проводником Android; доступ ко всему хранилищу
и к закрытым данным другого браузера не запрашивается.

Импорт добавляет отдельную папку и сохраняет прежние закладки. Поддерживается
формат Netscape Bookmark HTML, включая вложенные папки, названия и ссылки.
Разбор выполняется вне UI-потока штатным импортёром Fenix/Places. Повторный
импорт того же файла создаёт ещё одну папку; автоматического объединения нет.

Banana заявляет экспорт закладок в файл в своём
[описании Google Play](https://play.google.com/store/apps/details?id=org.triple.banana).
Если экспорт даёт HTML такого формата, его можно выбрать в Upgrid. Совместимость
с конкретной резервной копией пользователя нужно проверить по её формату;
проверка синтетического HTML не равна проверке настоящего файла Banana.

Экспорт полной истории Banana пока не подтверждён. Файл закладок не содержит
полную историю посещений. Для переноса истории нужен доступный экспорт самой
истории или документированный формат резервной копии. Upgrid не читает закрытую
базу другого приложения и не требует root. Импорт паролей/cookies этим выпуском
не добавляется.
