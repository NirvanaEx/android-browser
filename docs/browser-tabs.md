# Вкладки и сохранение состояния

Исправления от 14.09.2026 используют штатный режим Fenix `enableHomepageAsNewTab`.
Кнопки новой вкладки сразу добавляют отдельную `about:home` вкладку в BrowserStore,
с собственным ID и домашним экраном Upgrid. Ввод адреса не нужен для создания,
переключения или сохранения такой вкладки. Режим включается также при обновлении
установленного приложения; удалять профиль не требуется.

В прежнем режиме Fenix кнопка «+» только открывала поиск. Пока пользователь не
вводил адрес, новой вкладки в хранилище не было. Новое поведение применяется
через существующие пути списка вкладок, меню и панели браузера, без второго
хранилища сессий.

Связанная интеграция Fenix: сетевой `AppRequestInterceptor` больше не открывает
домашний экран при любом запросе `about:home`. Такой запрос может прийти поздно
или из фоновой пустой вкладки и закрыть интерфейс уже загруженной страницы.
Домашний экран открывает существующий `AboutHomeBinding` по актуальному URL
выбранной вкладки; перед переходом он перепроверяет состояние Store, чтобы
устаревшее событие не отменяло новую навигацию. Сам запрос `about:home` продолжает
проходить в движок.

При отправке адреса из уже созданной домашней вкладки `content.url` остаётся
`about:home` до асинхронного ответа Gecko. Общий `FenixBrowserUseCases` отмечает
намерение загрузки до вызова движка, и binding удерживает открытый экран браузера
в этот промежуток. Начиная с 0.6.7 временный реестр содержит ID всех вкладок с
незавершённым переходом. Смена вкладки и остановка binding при уходе в фон больше
не сбрасывают этот переход. Запись удаляется после подтверждённой смены URL,
закрытия вкладки или явной команды перейти домой. При
наблюдении учитывается также ID выбранной вкладки, чтобы различать две пустые
вкладки с одинаковым URL.

Ввод адреса и выбор поисковой подсказки сначала регистрируют и запускают загрузку,
затем открывают `BrowserFragment`. Это исключает синхронное чтение старого
`about:home` при открытии экрана. В `LinkingMiddleware` дополнительно отменяется
отложенная начальная загрузка `about:home`, если более новый прямой запрос
пользователя уже поступил в тот же engine session. Иначе первая загрузка новой
вкладки могла выполниться после адреса пользователя и вернуть движок домой.
Обычная начальная загрузка пустой вкладки сохраняется; второй runtime не создаётся.

Вторая причина частых перезагрузок — собственная политика `UpgridTabMemory`:
страницы вне пяти последних могли выгружаться уже через минуту. Минимальный
простой увеличен до 30 минут. Пять последних загруженных вкладок, выбранная
вкладка, медиа, формы, приватные страницы, загрузки и запросы разрешений защищены
как раньше. Свежая проверка формы и повторная проверка выбранной вкладки остаются
обязательными. Выгрузка освобождает движок страницы, но не удаляет вкладку или
её сохранённое состояние.

Проверенный pinned Fenix сохраняет обычные вкладки при изменении их количества,
выборе вкладки, завершении загрузки и уходе приложения в фон. Дополнительно
работает периодическое сохранение каждые 30 секунд; частые события объединяются
с минимальным интервалом 2 секунды. Используется штатный `SessionStorage` с
атомарным файлом. У обычных вкладок по умолчанию нет срока удаления:
`getTabTimeout()` возвращает `Long.MAX_VALUE`. Пользовательский выбор
автозакрытия через день/неделю/месяц сохраняется. Приватные вкладки не записываются
в постоянную сессию.

Это не гарантия сохранения произвольных JavaScript-переменных сайта после
завершения процесса Android. Gecko восстанавливает поддерживаемое состояние
сессии; система может освободить процесс раньше таймера Upgrid. Изменение таймера
устраняет собственную минутную выгрузку при обычном переключении вкладок.

## Проверки

`UpgridTabsTest` проверяет несколько пустых вкладок, их независимые ID,
переключение и восстановление через настоящий `SessionStorage` без созданной
engine session, сохранение старой обычной вкладки и исключение приватных данных.
`UpgridTabMemoryTest` проверяет границу 30 минут, сохранение пяти последних,
защиту форм/медиа и повторную проверку после асинхронного ответа Gecko.
`UpgridHomeRoutingTest` проверяет поздний/фоновый запрос домашней страницы,
устаревший снимок Store и сохранение обычного перехода на выбранную пустую вкладку.
Тест отправляет адрес через настоящий search middleware, FenixBrowserUseCases и
SessionUseCases с живой mock engine session, оставляет `content.url=about:home`
до отдельного location acknowledgement и проверяет отсутствие возврата домой
в этом промежутке.

`bash tools/fenix/test-tabs-player-import.sh` включает эти тесты и штатные тесты
создания/восстановления домашних вкладок. Для Android отдельно проверить:
создать три пустые вкладки без клавиатуры, переключить их, открыть сайт в одной,
уйти в фон и выполнить холодный запуск с сохранением профиля. Для живого состояния
страниц использовать `tools/tests/fixtures/tabs.html` с черновиком, прокруткой и
историей; проверка сериализации не заменяет проверку реального Gecko.
