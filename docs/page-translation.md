# Перевод страниц

Upgrid использует локальный перевод Firefox/Gecko: текст страницы не отправляется
в сторонний переводчик. Языковые модели загружаются штатным механизмом Firefox.
Первое скачивание модели и скорость процессора по-прежнему влияют на ожидание.

В кандидате 0.6.8 исходный язык определяет Gecko, а пользователь выбирает один
язык результата. Выбор сохраняется между запусками. Новый экран содержит поиск
по названию, коду и собственному названию языка, выбранную строку и переключатель
«Переводить автоматически». Исправить неверно определённый язык можно через
необязательную кнопку «Авто · …».

При включении автоперевода контроллер обрабатывает текущую и последующие страницы
на поддерживаемых языках. Учитываются исключения сайта/языка, Android Data Saver,
состояние загрузки, reader mode и уже выполняющийся перевод. Повторные обновления
состояния не дублируют запрос; «Показать оригинал» подавляет автоперевод этого
документа до нового перехода или перезагрузки. Исчезновение выбранного языка из
списка не заменяет его другим молча. URL страниц и определения языка в настройки
не записываются; сохраняются только язык результата и флаг автоперевода.

«Все языки» означает все исходные языки, поддерживаемые установленным движком и
его моделями. Это не добавление отсутствующих моделей и не отправка текста во
внешний сервис. По умолчанию автоматический режим выключен до выбора пользователя.

Изменение 0.6.7 объединяет короткие фрагменты одной страницы в один вызов Bergamot:
до восьми фрагментов и 8192 UTF-16 единиц суммарно. Более длинный исходный блок
обрабатывается отдельно. Фрагменты передаются отдельными элементами вектора,
каждый со своим HTML-флагом; их разметка не склеивается. Сохраняется соответствие
результатов исходным запросам, включая перевод через промежуточный язык.

Очередь собирается в течение 8 мс и отдаёт управление между пакетами. У каждого
документа собственная очередь с прежней отменой отдельных запросов и всей страницы.
Сохраняются приоритет видимой области, отложенный перевод за пределами экрана,
кеш, исключения `translate=no` и полей ввода, восстановление оригинала. Новые
модели, дополнительные вычислительные потоки и удалённые сервисы не добавляются.
Готовый текст применяется к DOM группами в штатном окне 25 мс. WASM-векторы и
дескрипторы ответов освобождаются как при успехе, так и при ошибке.

Переносимые изменения находятся в `tools/fenix/overlay/UpgridTranslationQueue.js`,
`TranslationBatch.body.js` и экспортируются в pinned Gecko через `apply-overlay.py`.
При упаковке APK нужно проверить фактическое содержимое `assets/omni.ja`:
исправления JavaScript должны попасть в артефакт даже при artifact build Gecko.

`tools/tests/translation-batch.test.cjs` запускает сгенерированные классы worker
с подменённым Bergamot и проверяет пакетность, порядок результатов, размеры,
отмену, изоляцию документов, pivot и освобождение памяти. Путь к worker передаётся
в `UPGRID_TRANSLATION_WORKER`. Это не замер скорости настоящей нейросети.

`tools/tests/fixtures/translation.html` содержит 32 английских абзаца, исключённый
текст и поле ввода. Локальный fixture server собирает только счётчики изменений
в `/translation-events`. Для проверки использовать настоящую модель en→ru,
прокрутить страницу, восстановить оригинал и повторить перевод с уже загруженной
моделью. Сравнивать одну и ту же страницу и одинаковую область экрана. Холодное
скачивание моделей не смешивать с временем вычисления; время эмулятора не считать
оценкой скорости пользовательского устройства.
